# 프론트 처음 시작하기

1. [개발 환경과 물품 관리](https://github.com/mackerel07/opensourcebasic/issues/14)에서 Node.js 22 LTS, npm, Next.js와 TypeScript로 `frontend/`를 준비합니다.
2. [반납 사진과 결과 화면](https://github.com/mackerel07/opensourcebasic/issues/15)에서 사진 촬영·선택부터 미리보기, 샘플 결과 수정·확인까지 만듭니다.

초기 세팅이 끝나면 저장소의 최상위 폴더에서 실행합니다.

```bash
cd frontend
npm ci
npm run dev
```

브라우저에서 이번 이슈의 기본 동작을 확인하고 PR에 확인 방법을 한 줄 적습니다. 브랜치와 PR 규칙은 [CONTRIBUTING.md](../CONTRIBUTING.md)를 봅니다.

화면 작업은 임시 데이터로 진행합니다. 실제 자료와 API 연결은 [사전 검토](REVIEW_GATE.md) 승인 후 진행합니다.
