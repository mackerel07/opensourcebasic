# 공용 물품 반납 확인 웹 프로젝트

공용 물품을 관리하고, 휴대폰 사진으로 반납 상태를 확인하는 팀 프로젝트입니다. 저장소에 모델 실행 코드와 협업 문서를 두고 있습니다.

## 작업 이슈

| 담당 | 작업 |
| --- | --- |
| 프론트 | [개발 환경과 물품 관리](https://github.com/mackerel07/opensourcebasic/issues/14) → [반납 사진과 결과 화면](https://github.com/mackerel07/opensourcebasic/issues/15) |
| 데이터 | [물품 사진과 정답 자료 준비](https://github.com/mackerel07/opensourcebasic/issues/16) |
| 모델 | [실행 환경과 사진 처리](https://github.com/mackerel07/opensourcebasic/issues/17) → [분류기 학습과 평가](https://github.com/mackerel07/opensourcebasic/issues/18) |
| 실제 연결 | [데이터·API 검토와 웹 데모](https://github.com/mackerel07/opensourcebasic/issues/19) |

프론트는 임시 데이터로 시작합니다. 데이터 확보안은 수집·정리 전에, Supabase·API·모델 서빙 계획은 실제 연결 전에 저장소 소유자에게 검토받습니다.

[Git 협업 규칙](CONTRIBUTING.md) · [프론트 실행 안내](docs/FRONTEND_START.md) · [데이터·API 사전 검토](docs/REVIEW_GATE.md)

모델 담당자는 [설치·실행 안내](model/README.md)와 [실행 검증 결과](model/evidence/README.md)를 참고합니다.
