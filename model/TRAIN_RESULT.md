# dataset-v1 초기 학습 결과

2026-11-17, Apple M4 CPU에서 실제 단독 사진으로 DINOv2 고정 특징과 로지스틱 회귀 분류기를 학습했다. [실행 계획](TRAIN_PLAN.md), [선택한 crop·분할·해시](dataset_v1_selection.csv), [집계 JSON](dataset_v1_training_summary.json)을 함께 남겼다.

## 자료와 정답 영역

원본 단독 사진 31장은 계산기 10장, 가위 8장, 마우스 13장이다. 원본 사진과 반납 평가 사진 12장을 포함한 43장 모두 읽기 검사를 통과했고 파일 SHA-256이 같은 중복은 없었다. 유사 장면 간 독립성은 추가 확인이 필요하다.

자동 후보에서 선택한 전체 물품 crop은 22개다. 가위 8장과 마우스 1장에서는 전체 물품 후보를 확보하지 못해 사람이 박스와 양성 점을 지정한 SAM2 마스크로 보완했다. 보완된 후보는 원본을 보며 확인했다. 자동 후보 생성 성능이 31/31이라는 뜻으로 사용하지 않는다. 보완 좌표로 후보를 다시 생성해 27개 crop 파일이 동일하게 나오는 것도 확인했다.

| 분할 | 원본 사진 | 계산기 | 가위 | 마우스 | 배경 other | 전체 crop |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 학습 | 23 | 8 | 5 | 10 | 16 | 39 |
| 검증 | 8 | 2 | 3 | 3 | 3 | 11 |

촬영 시각을 참고한 임시 그룹 3개 중 2개는 학습, 1개는 검증으로 배정했다. 같은 원본의 물품·배경 crop은 같은 분할이다. 회차는 촬영자에게 확인되지 않았으며 같은 실물이 양쪽에 있다. 검증 crop 11개는 서로 독립인 원본 사진 11장이 아니라 원본 8장에서 나온 자료다.

## 특징 추출과 학습

SAM2.1 Small과 DINOv2 ViT-S/14는 고정했다. 각 crop을 회색 여백을 포함한 224×224로 전처리해 384차원 특징을 추출했고, 유한한 값의 50×384 행렬을 확인했다. L2 정규화 뒤 로지스틱 회귀만 학습했다.

| C | 검증 정확도 | 검증 Macro F1 |
| ---: | ---: | ---: |
| 0.1 | 11/11 | 1.000 |
| 1 | 11/11 | 1.000 |
| 10 | 11/11 | 1.000 |
| 100 | 11/11 | 1.000 |

기존 선택 규칙에 따라 동점에서 가장 작은 C=0.1을 선택했다. 검증 자료로 재학습하지 않았다.

학습 정확도는 39/39, 검증 정확도는 11/11이다. 검증 품목별 정답은 계산기 2/2, 가위 3/3, 마우스 3/3, 배경 3/3이다. 이는 사람이 확인·보완한 crop을 네 종류 중 하나로 고른 argmax 결과다. 표본이 작고 같은 실물이라 과적합이나 새 물품·환경에 대한 일반화를 확인하기에는 부족하다.

## 현재 자동 판단의 한계

선택된 모델의 검증 최고 점수는 약 0.299~0.368이다. 기존 자동 확정 기준인 최고 점수 0.7 이상·점수 차이 0.15 이상을 동시에 통과한 검증 crop은 **0/11**이다.

저장한 분류기를 실제 자동 마스크 파이프라인에 연결해 개발용 단독 사진 두 장을 실행했다.

| 사진 | 자동 후보 | 상태 | 자동 확정 수량 | 추론·후처리 시간 |
| --- | ---: | --- | --- | ---: |
| calculator_01 | 15 | review | 세 품목 모두 0 | 약 12.0초 |
| scissors_06 | 1 | review | 세 품목 모두 0 | 약 11.7초 |

위 두 장은 학습·검증에 이미 사용한 개발 사진이다. 시간은 각 1회 측정이며 모델 로드·입출력 시간을 제외한다. 반납 정답표 기준 성능을 계산한 실험과 구분해 기록했다.

## 다음 진행

1. 가위 전체 마스크를 자동으로 유지하는지 학습·개발 사진에서 개선한다. 자동 후보가 없는 물품은 뒤의 분류기를 잘 학습해도 복구할 수 없다.
2. 별도 개발용 반납 장면에서 점수·점수 차이 기준과 확인 요청 정책을 정한다. 검증 argmax가 모두 맞았다는 이유로 자동 확정 기준을 임의로 낮추지 않는다.
3. 촬영 회차를 확인하고 새로운 배경·빛·겹침 및 미등록 실물 자료를 보강한다. 현재 other은 책상·종이·매트 중심이다.
4. 후보 생성·분류기·판정 기준을 고정한 뒤 보관한 반납 사진 12장으로 전체 수량·누락 오판·확인 요청·실패를 평가한다. 이번 작업에서는 12장에 모델 추론을 실행하지 않았다.

학습 산출물은 로컬의 `runs/dataset_v1/model/head.joblib`이다. 원본 사진·crop·환경·모델 파일을 Git에 추가하지 않고 계획, 선택 근거, 코드, 집계 결과를 남겼다. 실제 API와 웹 연결은 #19의 사전 검토 후 진행한다.
