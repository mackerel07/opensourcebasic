# 물품 사진 데이터셋 v1

Issue #16에서 준비한 계산기·가위·마우스 촬영 자료입니다.

## 다운로드

[데이터셋 릴리스](https://github.com/mackerel07/opensourcebasic/releases/tag/dataset-v1)의 Assets에서 `_.zip`을 받습니다.
압축을 풀면 `single/`과 `return_eval/`, 사진 목록과 정답표가 있습니다.
저장소 협업 규칙에 따라 개인 촬영 사진은 릴리스로 전달합니다.

## 구성

| 용도 | 품목 | 사진 수 |
|---|---|---:|
| 단독 | 계산기 | 10 |
| 단독 | 가위 | 8 |
| 단독 | 마우스 | 13 |
| 반납 평가 | 정상·누락·겹침·수량·미등록 물품 | 12 |

[단독 사진 목록](단독_사진_목록.md)과 [반납 평가 정답표](반납_평가_정답표.md)에 ZIP 내 경로와 원본 파일명을 기록했습니다.
공개 데이터셋 사진은 선정본에 포함되지 않습니다.

## 사용 시 확인

- 단독 사진의 촬영 회차와 학습·검증·평가 분할은 미확인 상태입니다.
- 반납 평가 사진 12장은 평가 전용으로 보관합니다. 같은 원본에서 만든 자르기와 마스크도 학습·설정 조정에 사용하지 않습니다.
- Issue #16의 품목별 20장 목표에 비해 계산기 10장, 가위 12장, 마우스 7장이 부족합니다. 계산기 한 컷은 프레임 여백이 작습니다.
- 현재 수량의 수용 여부와 분할 계획은 리뷰에서 확인이 필요합니다.
